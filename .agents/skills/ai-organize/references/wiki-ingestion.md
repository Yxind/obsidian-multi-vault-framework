# Confirmed Wiki ingestion

Read this reference only after the user explicitly confirms ingestion.

Before writing, ensure a detailed summary exists, inspect the source and summary, read `3-Wiki/index.md`, and search relevant existing pages.

For each confirmed candidate:

1. Select the canonical owner using `knowledge-ownership.md`.
2. Link, update, create, or keep local; never create a synonym page for convenience.
3. Add the Vault's required Wiki metadata, including non-empty `sources` and `last_reviewed`.
4. Link the page to the detailed summary and list the page reciprocally in the summary.
5. Separate facts, synthesis, inference, judgment, and pending verification; date time-sensitive claims.
6. Keep private source detail inside the authorized private Vault. Move only explicitly authorized, redacted, generalizable material across its boundary.
7. Update the index only when a canonical page or reading route changes, and append the local maintenance log when the Vault uses one.

After successful completion, mark the detailed summary `archived` and retain it. Delete the rough file unless the user genuinely intends to resume remaining scope; in that case retain the `-待继续` file and record progress.

If the user declines ingestion, delete the rough file. Retain any existing detailed summary with the decision recorded unless the user asks to remove it.
